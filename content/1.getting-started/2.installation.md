## Install via Composer

```bash [Terminal]
composer require xefi/laravel-osdd
```

The package uses Laravel's **package auto-discovery** — `LaravelOSDDServiceProvider` is registered automatically. No manual registration needed.

## Publish the Config (optional)

```bash [Terminal]
php artisan vendor:publish --provider="Xefi\LaravelOSDD\LaravelOSDDServiceProvider"
```

This creates `config/osdd.php` in your project root.

## Configuration

```php [config/osdd.php]
<?php

return [
    'layers' => [
        'paths' => [
            'functional' => base_path('functional'),
            'technical'  => base_path('technical'),
        ]
    ]
];
```

| Key | Default | Description |
|-----|---------|-------------|
| `layers.paths.functional` | `{project_root}/functional` | Root directory for domain/business layers |
| `layers.paths.technical` | `{project_root}/technical` | Root directory for infrastructure layers |

::tip
You can add as many named path buckets as you like. When more than one exists, `osdd:layer` will prompt you to choose which bucket a new layer belongs to.
::

## IDE Helper Integration

If you use [`barryvdh/laravel-ide-helper`](https://github.com/barryvdh/laravel-ide-helper), OSDD automatically merges every layer's `src/` directory into `ide-helper.model_locations` whenever `php artisan ide-helper:models` runs. Existing entries are preserved and de-duplicated — no manual config is needed for `ide-helper:models` to discover models that live inside layers.

```bash [Terminal]
php artisan ide-helper:models
# scans:
#   - the locations you've configured yourself (e.g. "app")
#   - every {functional,technical}/{layer}/src directory discovered by OSDD
```

## Next Steps

Once installed, you have two options:

- **Fresh project** — run [`osdd:start`](/commands/osdd-start) to bootstrap the full OSDD architecture in one command.
- **Existing project** — run [`osdd:layer`](/commands/osdd-layer) to add individual layers incrementally.
