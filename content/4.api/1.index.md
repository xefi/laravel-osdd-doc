Laravel OSDD exposes the following classes for use in your layer service providers and application code.

::card-group
  :::card
  ---
  icon: i-lucide-plug
  title: LayerServiceProvider
  to: /api/layer-service-provider
  ---
  Abstract base class for every layer's service provider. Provides `loadSeeders()` and `overrideConfigFrom()`.
  :::

  :::card
  ---
  icon: i-lucide-database
  title: SeederRegistry
  to: /api/seeder-registry
  ---
  Singleton that collects seeder class-strings from all layers. Used by `osdd:seed`.
  :::

  :::card
  ---
  icon: i-lucide-folder-search
  title: LayersCollection
  to: /api/layers-collection
  ---
  Discovers and collects all valid layers from the configured paths.
  :::
::
